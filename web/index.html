Drift compares Kubernetes' OWNERS files with the merged pull requests, reviews, /lgtm and /approve commands in kubernetes/kubernetes. Work in other repositories isn't counted, so "silent" means silent here, not gone. Only public GitHub handles are stored. Drift never edits Kubernetes: every change is a draft for a maintainer. Runs on FalkorDB.
